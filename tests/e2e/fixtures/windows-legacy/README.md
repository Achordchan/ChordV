# Windows 历史迁移夹具

`baseline.json` 保留原有 Windows 验收脚本中的真实 1.1.7 发布地址、文件名、SHA256 和历史可执行文件名；没有下载、重打包或生成替代安装包。此处摘要来自既有固定夹具，不代表本轮已联网核验远端资产。

`windows-shell-link.ps1` 原样保留 Unicode `IShellLinkW` 辅助代码，可供未来 Windows 实机测试对真实旧版本路径创建和读取快捷方式。它本身不下载安装包、不启动客户端、不改系统代理。

后续 Windows 实机迁移应使用真实旧版资产并先核对固定摘要，检查中文自定义目录、用户快捷方式、原有会话与代理恢复，以及只清理 ChordV 自有进程。旧验收脚本专属的维护参数、旧 updater 安装参数、启动门禁和目录布局不再作为 MyGo 的实现合同。

当前回归验证 MyGo 安装授权、摘要校验和清理/交接顺序，并执行真实 Go 签名、授权、防回滚和本地 HTTP 下载行为测试；这些不等于已经验证 Windows 实际安装、旧版升级或快捷方式迁移。
